# KIDULTS Final Master Design

Status: CANONICAL / FROZEN
Effective date: 2026-08-11
Owner: Intelligence Holdings / KIDULTS
Supersedes: earlier public visual baselines where they conflict with this document.

## Master declaration

This document is the single canonical visual specification for the KIDULTS public intelligence portal. Implementation must reproduce this master; it must not reinterpret it.

The approved direction is a global premium luxury intelligence platform expressed through restraint, evidence, quiet authority and editorial precision.

`K I D U L T S`

- uppercase sans serif;
- generous tracking;
- dark Primary Ink;
- approximately 20px at the reference desktop scale;

`K I D U L T S`

- same corporate signature;

- quiet secondary signature;
- no serif `Kidults.` variant;
- no decorative box, gradient, icon or gold treatment.

### Locked preview objects

The five master objects are visually fixed as follows:

1. **Mobility** — low ivory mobility sculpture, black canopy, simplified surfaces.
2. **Time** — pale circular stone/ivory time object on a simple rectangular base.
3. **Footwear** — monochrome ivory/white sneaker abstraction without recognizable third-party trade dress.
4. **Character** — small neutral koala-like sculptural figure, generic/non-branded, small nose, natural arms/hands.
5. **Design** — pale sculptural bowl/lounging-chair form, neutral and simplified.

The purpose is not to reproduce commercial products. The object language is editorial, original, neutral and rights-safe.

## 9. Typography hierarchy

- Corporate wordmark: uppercase tracked sans serif.
- Editorial headline: premium serif.
- Section headlines: editorial serif where shown by the master.
- Navigation / labels / controls / metadata: restrained sans serif.
- Data values: premium numeric hierarchy, never decorative.

The wordmark and editorial headline intentionally use different type languages. The contrast is part of the master identity.

## 10. Color hierarchy

Canonical typography colors:

- Primary Ink `#0B1713`
- Forest Intelligence `#073D2D`
- Secondary Ink `#303733`
- Muted Evidence `#70756F`

Canonical surface colors:

- Paper `#FAF9F6`
- Paper Warm `#FAF8F4`
- Paper Card `#FBFAF7`
- Line `#DDD9D2`

Forest means active, verified, intelligence-bearing or primary action. Gold is not a default public-master decoration.

See `KIDULTS_VISUAL_COLOR_POLICY.md` for the full policy.

## 11. Layout language

- warm ivory canvas;
- restrained rounded cards;
- hairline borders;
- generous whitespace;
- low visual noise;
- no heavy dark footer;
- no duplicate decorative object rails;
- no uncontrolled horizontal overflow.

The public master should feel closer to an editorial intelligence institution than to a marketplace, gallery grid or generic SaaS dashboard.

## 12. Responsive principle

There is one master design, not separate desktop and mobile concepts.

Responsive implementation must preserve:

- typography hierarchy;
- object order;
- evidence hierarchy;
- rights-safe visual language;
- CTA priority;
- Canon Strength semantics;
- footer signature hierarchy.

Required review widths: 320, 375, 390, 430, 768, 1024, 1280, 1440, 1600 and 1920px.

## 13. Data integrity principle

Every production number should be traceable through provenance:

`Source → Collection → Normalization → Verification → Confidence → Timestamp`

If a value is unavailable or unverified, show an unavailable/pending state. Never infer `0` or `0%` from null evidence.

## 14. Change control

The following are frozen unless the owner explicitly requests a new design revision:

- uppercase KIDULTS wordmark;
- current header scale and tracking;
- smaller footer wordmark;
- hero composition and copy;
- single hero mobility object;
- ivory / Forest / Ink visual language;
- Institutional Intelligence Layer;
- five-stage methodology;
- Kidult 100 five-object composition and rights-safe forms;
- Canon Strength location and vocabulary;
- three-column lower intelligence structure;
- institutional bottom layer;
- lightweight footer;
- `500+ Tracked Entities` terminology.

## 15. Implementation rule

The approved visual master is the design authority. Existing staging HTML/CSS that differs from this document is implementation debt, not a competing design baseline.
