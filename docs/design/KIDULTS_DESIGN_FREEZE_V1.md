# KIDULTS Design Freeze v1

Status: Approved baseline
Scope: Public, Provider, Monthly Intelligence, Archive, Methodology and Operations interfaces

## 1. Brand principle

KIDULTS presents decision-ready collectibles intelligence with restrained authority. The interface must prioritize trust, comparability and evidence over decoration.

## 2. Color system

Primary visual language is Forest Green Monochrome.

- Forest 900: #0B3B31
- Forest 700: #245E50
- Forest 500: #5F9180
- Forest 300: #A9C7BC
- Paper: #F4F1EA
- Ink: #111815
- Editorial gold accent: #B9934D

Gold is accent-only. It may be used for edition, verified, premium and editorial labels. Gold must not be used as the primary chart, ring or dashboard visualization color.

## 3. Hero system

The public Hero is frozen as:

- Editorial serif headline
- Forest Intelligence Dial
- Integrated Kidult 100 Index value
- Current Edition badge as a restrained gold accent
- Compact evidence rows for confidence, coverage, source families, update time and methodology
- Hero copy remains the primary visual entry point; the dial must support rather than overpower it

## 4. Typography

- Hero and major section headings: editorial serif
- Navigation, labels, buttons and dashboard copy: sans serif
- Numeric data: lining and tabular figures
- No page-level font substitutions without design-system approval

## 5. Visualization

- Primary chart palette: Forest 900 through Forest 300
- Gold prohibited as a primary visualization color
- Percentage charts use a 0-100 scale
- Score charts use a stated 0-100 scale
- Relative comparisons must be explicitly labelled
- Donut center labels remain subordinate to the numeric value
- Legends must follow segment order

## 6. Category Intelligence

- Desktop and tablet: two-column category-card layout
- Mobile: single-column layout
- Confidence, velocity, liquidity and state remain visible
- Card height, bar geometry and metadata spacing must remain consistent

## 7. Signal Composition

- Panel height follows content and must not stretch to fill adjacent columns
- No decorative empty space
- Composition total, legend and detailed dimensions remain grouped

## 8. Layout and spacing

- 8px spacing grid
- Consistent section spacing and card gutters
- No horizontal overflow at 320px and above
- Hero, KPI strip, live intelligence note and Trend preserve clear vertical separation

## 9. Motion

Approved motion only:

- subtle fade
- restrained ring reveal
- live pulse
- chart tooltip transition

Motion target is 0.45 seconds or less. Reduced-motion preferences must be respected.

## 10. Accessibility and quality gates

- Keyboard-visible focus
- Semantic labels and chart alternatives
- WCAG-aware text and data contrast
- Mobile QA at 320, 375, 390 and 430px
- Desktop QA at 1280, 1440, 1600 and 1920px
- No broken internal links
- No illustrative data presented as validated production data

## 11. Governance

This document freezes the approved KIDULTS public design baseline. Future changes require a documented reason tied to accessibility, data integrity, business conversion or a reusable design-system improvement. Cosmetic experimentation alone is not sufficient.
