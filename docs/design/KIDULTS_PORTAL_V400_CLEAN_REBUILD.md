# KIDULTS Portal V400 — Clean Rebuild

## Objective

Replace the compressed dashboard presentation with a long-form institutional intelligence portal while preserving the approved Hero and five rights-safe Kidult 100 object assets.

## Locked visual assets

- Wide Hero mobility canvas
- Mobility object
- Mechanical time object
- Archive runner object
- Koala character object
- Lounge chair object

## V400 layout rules

- One canonical stylesheet: `portal-v400.css`
- Existing data/runtime connector retained through `portal-v300.js?v=400`
- Header height: 88px desktop
- Hero canvas: 610px desktop
- Executive metrics: 3 × 2 grid instead of a compressed six-card strip
- Section rhythm: 88–126px
- Body copy: generally 13–18px
- Critical labels: 10.5px or larger
- Kidult 100 card height: approximately 510px desktop
- Kidult 100 figure stage: 190px
- Market signals: 2 × 2 grid
- Evidence cards: 430px minimum
- Research, Archive and Institution are full editorial sections
- Footer height: 112px

## Responsive rules

- Desktop: full institutional portal
- Tablet: two-column cards and stacked Hero
- Mobile: single-column flow, no horizontal page overflow, 44px minimum controls

## Data integrity

The existing runtime keeps preview baselines visibly distinct from verified values. Null quality feeds do not overwrite public preview values with false zeros.
