# KIDULTS Portal V500 — Design Freeze

## Frozen visual system

- Uppercase tracked KIDULTS wordmark
- Ivory / Forest / Ink color system
- Editorial serif hierarchy with restrained sans-serif metadata
- Approved wide mobility Hero canvas
- Approved five rights-safe Kidult 100 objects
- 20px primary card radius and quiet 1px borders
- 1440px shell with responsive gutters
- Readable metadata floor of approximately 10.5px
- Long-form institutional page rhythm
- Research, Archive and Institutional closing sequence

## V500 final corrections

1. Hero vehicle reduced optically; studio canvas widened.
2. Snapshot and Operational Evidence responsibilities separated.
3. Kidult 100 changed from product-card density to editorial-gallery presentation.
4. Market Signals upgraded with trend, change, source count and freshness.
5. Desktop, tablet and mobile behavior consolidated into one stylesheet.

## Post-freeze rule

After V500, visual changes require a recorded design decision.
Default product effort moves to data, ranking, search, reports and autonomous intelligence.
