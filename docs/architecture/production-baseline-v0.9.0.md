# KAIOS Production Baseline v0.9.0

This baseline certifies the first formal KAIOS production release
candidate.

Included capabilities:

- autonomous collection and processing runtime
- persistent runtime history
- scheduler and execution locking
- containerized gateway and scheduler
- typed production configuration and secret loading
- authentication, role-based access control, and rate limiting
- security headers and audit logging
- structured observability, metrics, and alerts
- verified backup and restore
- release gating and rollback validation
- semantic versioning and production deployment certification

The v0.9.0 baseline is approved for controlled pilot and single-node
production operation. Multi-node orchestration, external load
certification, and broader disaster-recovery drills remain post-v0.9.0
work.
