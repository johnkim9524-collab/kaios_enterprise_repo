# Kidult 100 POC Scale-Up Plan

Status: EXECUTION PLAN
Date: 2026-08-10

## Objective

Scale the live external-data POC from a narrow proof into a repeatable, rights-aware operating system that can support a 300+ candidate universe, a future 100-constituent benchmark, category-specific intelligence and stable portal products.

The POC is successful only when it proves live collection, data quality, rights/provenance, entity continuity, WHY generation, operational resilience and product-contract delivery.

## Stage 0 — Control Foundation

Target: complete immediately.

Requirements:
- canonical value thesis
- 8 Core Verticals + dynamic expansion contract
- 13 source classes
- 7 intelligence primitives
- Source Rights Gate
- Unified Autonomous Preflight
- stable portal data contracts
- live open-data collector

Exit gate:
- governance documented
- no automated source activated without known rights basis
- synthetic and live evidence explicitly separated

## Stage 1 — 100 Live Candidates

Target universe: >=100 unique real external candidates.

Goals:
- prove 8-vertical discovery coverage
- 100% source/timestamp/rights/provenance fingerprinting
- map every accepted observation to at least one intelligence primitive
- create canonical entity records
- measure source failure, latency and duplicate contamination

Exit targets:
- unique candidates >=100
- provenance coverage =100%
- rights classification =100%
- primitive mapping =100%
- duplicate contamination <0.5%
- no unsupported final Kidult 100 claim

## Stage 2 — 300 Candidate Universe

Target universe: >=300 qualified candidates.

Goals:
- minimum viable representation across all Core Verticals
- Candidate x Primitive x Source x Rights x Field matrix
- vertical-specific data sufficiency scoring
- daily candidate reconciliation
- stable candidate lifecycle states

Exit targets:
- >=300 candidates
- all 8 Core Verticals represented
- >=2 source classes for high-priority candidates where feasible
- entity resolution >=99.5% on golden sample
- rights/provenance coverage 100%

## Stage 3 — 500 Candidate Operating Reserve

Target universe: 400-500 monitored candidates.

Goals:
- create redundancy behind the future published 100
- detect category rotation without redesigning the benchmark
- begin historical observation accumulation
- establish source fallback for critical primitives
- introduce source health scores

Exit targets:
- >=400 monitored candidates, target 500
- no single source class critical dependency for identity/provenance
- source outage simulation and fallback evidence
- daily refresh and reconciliation evidence

## Stage 4 — Market Intelligence Activation

Goal: move from identity/canon POC to actual market intelligence where legal source rights are available.

Activate only rights-approved channels for:
- sold transactions
- auction results
- asking inventory
- supply state
- liquidity
- grading/population
- demand/attention

Critical classification rules:
- SOLD != ASKING
- RETAIL != SECONDARY
- TRANSACTION != ESTIMATE
- COMMUNITY ATTENTION != MARKET DEMAND

Exit targets:
- transaction/price observations normalized for time and currency
- sold/asking classification 100%
- material market claims backed by evidence
- liquidity only scored where actual evidence exists

## Stage 5 — Vertical Intelligence DNA

Goal: prove that category-specific intelligence materially improves quality.

For every Core Vertical define:
- factor model
- required fields
- condition taxonomy
- comparable logic
- scarcity logic
- risk logic
- WHY causal model
- source priority map

Exit target:
- each vertical has a tested scoring contract and WHY examples using real evidence

## Stage 6 — WHY Graph & Longitudinal Intelligence

Goal: begin building the irreplaceable asset.

Persist:
- signal events
- cause candidates
- supporting evidence
- counter evidence
- confidence changes
- outcomes
- invalidations

Exit targets:
- material score/rank movement WHY coverage =100%
- unsupported causal claims =0
- replayable explanation history

## Stage 7 — Kidult 100 Shadow Index

Goal: run the benchmark internally before public publication.

Requirements:
- >=300 qualified candidate universe
- 100 shadow constituents
- vertical score + cross-category normalization
- diversification constraints
- rank movement explanation
- confidence and evidence visibility

Run cadence:
- daily internal recomputation
- weekly benchmark review
- no external production publication without publication gate

Exit targets:
- deterministic rerun 100%
- rank changes traceable to evidence
- methodology drift controlled

## Stage 9 — Unattended Operations

Goal: prove real autonomous operation within bounded authority.

Measure:
- collection success rate
- source health
- stale-data rejection
- retry/recovery
- manual intervention rate
- alert precision
- evidence completeness
- cost per decision-grade observation

Targets:
- critical silent failure =0
- routine manual intervention <1% directionally
- automated recovery >95% initially, >99% target
- provenance 100%

## Stage 10 — Scale & Capacity Proof

Scale profiles:
- 1K objects
- 10K objects
- 100K objects / comparable entities
- 1M+ observations
- 5M+ observations

Prove:
- ingest throughput
- entity resolution throughput
- graph lookup latency
- scoring latency
- replay/recovery
- cost per 1K observations

## Stage 11 — External GA Readiness

Technology GA:
- engineering, security, SRE, deterministic CI, preflight, recovery

Data GA:
- real rights-approved data, quality thresholds, provenance, historical continuity

Operational GA:
- controlled live operation, low intervention, measured recovery and observability

Commercial GA:
- willingness-to-pay, retention/usage, product-level economics, lawful commercial rights

True 120 requires all four. No simulation may substitute for external proof.
