# KIDULTS ASI Intelligence Preparation Wave v1

**Owner:** KPMO  
**Priority:** P0  
**State:** Executable SHADOW preparation  
**Direction:** Autonomous → Global → Irreplaceable Value → Transparent

## Purpose

This wave turns the current Global Source Mesh into executable preparation assets. It does not wait for a named provider, external contract, or manual source list. It starts from the platform's explicit unknowns and produces the next bounded missions automatically.

The wave is not a document-only roadmap. The GitHub workflow builds, validates, mutation-tests, receipts, and artifacts the following eight modules on every relevant main change, every three hours, and after the Global Source Mesh or Source Fabric Scale workflow succeeds.

## 1. Unknown Registry

Every unresolved market cell is represented explicitly. Missing evidence remains `UNKNOWN`; it is never converted to zero, negative evidence, or a market fact.

The first executable baseline contains all:

```text
32 scopes × 3 regions × 8 evidence classes = 768 unknown records
```

Each record preserves scope, domain, archetype, region, evidence class, source-lane state, claim ceiling, four-principle vector, expected information gain, dependency risk, and evidence lineage.

## 2. Intelligence Gap Engine

Unknown debt is aggregated without losing the underlying market-cell lineage across:

- evidence class;
- scope;
- region;
- domain;
- archetype.

The output identifies the highest decision-relevant gaps while preserving the truth that the current computable market surface remains zero until admitted evidence exists.

## 3. Autonomous Mission Generator

The first queue contains 192 bounded missions:

```text
96 CURRENT_SOLD_TRANSACTION missions
+
96 LIQUIDITY_TIME_TO_SALE_EXPOSURE missions
=
192 missions
```

This covers all 32 scopes and all three governed regions for the two most decision-critical evidence classes.

Every mission is limited to discovery and preflight. It must identify a primary candidate lane, an independent fallback lane, a distinct factual-origin replacement lane, and the rights/semantic/technical evidence required for Gate 1, Gate 2, and Gate 3.

## 4. Provider Replaceability

Every mission receives three mandatory operational slots:

1. Primary candidate lane;
2. Independent fallback lane;
3. Distinct factual-origin replacement lane.

The first wave therefore creates 576 explicit replaceability slots. No named provider is preselected, and no provider may become a mandatory path to canonical truth, an index, or a projection.

## 5. Intelligence ROI

Missions are ranked only after all four platform directions pass their hard floors.

```text
Expected Intelligence Gain
÷
(Expected Cost × (1 + Dependency Risk / 5))
```

The score is advisory. It cannot create collection rights, evidence admission, or a claim.

## 6. Cross-Category Intelligence

The system produces 24 testable cross-category evidence demands:

```text
3 regions × 8 evidence classes = 24 hypotheses
```

Each hypothesis spans multiple domains and asks whether shared capital-flow, collector-behavior, or market-structure patterns may exist. A hypothesis is never a fact, and correlation is never silently promoted to causation.

## 7. Portfolio Intelligence

The portfolio map exposes domain-level scope coverage, unknown debt, critical mission load, and evidence concentration. It does not compute KIDULT 500, KIDULT 100, or any other market index.

## 8. Self Calibration

Every mission receives a calibration obligation binding:

- predicted unknown reduction;
- predicted intelligence gain;
- predicted ROI;
- expected global coverage gain;
- expected KIDULTS-owned value gain.

Realized values remain `WAITING_FOR_EVIDENCE` until an evidence-backed result exists. Predictions cannot be silently rewritten after execution.
