# KIDULTS ASI Mission Consumption Wave v1

**Owner:** KPMO  
**Priority:** P0  
**Direction:** Autonomous → Global → Irreplaceable Value → Transparent

## Purpose

This wave consumes the 192 missions already generated by the Intelligence Preparation Wave. It performs bounded live public-metadata discovery and converts the results into traceable source candidates, candidate replaceability slots, provider-health evidence, and explicit remaining gaps.

It is the first execution step after mission generation:

```text
192 Autonomous Missions
        ↓
64 Scope × Evidence-Class Query Groups
        ↓
Live Public-Metadata Discovery
        ↓
Source Candidate Increment
        ↓
Primary / Independent Fallback / Factual-Origin Replacement Candidates
        ↓
Rights, Identity, Semantics, Technical and Origin Preflight Demand
```

## Mission coverage

The queue covers:

```text
32 scopes × 3 regions × 2 critical evidence classes = 192 missions
```

The two evidence classes are:

1. `CURRENT_SOLD_TRANSACTION`
2. `LIQUIDITY_TIME_TO_SALE_EXPOSURE`

Network requests are grouped by scope and evidence class, producing 64 query groups while preserving all three regional missions in every group.

## Live discovery lanes

### GDELT public document metadata

GDELT is used only to discover current public publisher URLs and domains containing transaction or liquidity terminology. Article metadata is not treated as a sold record, liquidity measure, or market evidence.

### Wikidata official website graph

Wikidata entity search and property `P856` are used only to discover official websites attached to potentially relevant public entities. An official website is not collection permission and is not automatically a relevant market source.

Both lanes use bounded `GET` requests. The workflow does not crawl the body of any discovered target site.

## Candidate evaluation

Every candidate preserves:

- canonical URL and host;
- discovery lane and authority;
- query-group lineage;
- scope and evidence class;
- observed time;
- semantic signal score and reason codes;
- region match state;
- candidate factual-origin identifier and uncertainty state;
- raw response digest and evidence references;
- explicit rights and admission state.

A source candidate remains:

```text
DISCOVERED_METADATA_ONLY_PREFLIGHT_REQUIRED
```

## Replaceability slots

Every mission evaluates three slots:

1. **Primary candidate**
2. **Independent fallback**
3. **Factual-origin replacement**

A discovered candidate may fill a slot only as:

```text
CANDIDATE_IDENTIFIED_PREFLIGHT_PENDING
```

It does not create an operational provider binding. The fallback requires a distinct host, and the factual-origin replacement requires a distinct candidate origin.

## Mission states

Each mission ends the cycle in exactly one state:

- `CONSUMED_CANDIDATES_DISCOVERED_PREFLIGHT_PENDING`
- `CONSUMED_PARTIAL_CANDIDATE_COVERAGE`
- `CONSUMED_NO_CANDIDATE_DISCOVERY_GAP_REMAINS`
- `CONSUMED_PROVIDER_FAILURE_BLOCKED`

Provider failure is never reported as empty market activity. An empty discovery result is never reported as zero demand, zero sales, or absence of a market.

## Automatic execution

```text

or hourly schedule at :17
or successful Intelligence Preparation / Source Fabric Scale run
        ↓
Rebuild current 192-mission queue
        ↓
Execute 64 live discovery query groups
        ↓
```

Manual dispatch remains only for recovery or explicit replay.
