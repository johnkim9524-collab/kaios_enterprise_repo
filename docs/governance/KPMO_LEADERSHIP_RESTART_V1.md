# KPMO 운영 개편과 전략 우선 실행

결정: #2424 댓글 5901775802. 선임심의 종결과 실제 가동 완료는 구분한다. 후속: #2431.

Atlas는 기존 직무를 유지하며 사전 전략·우선순위·통합·시간/비용·종단 간 종결에 책임진다. 초대 Deputy는 X4 Codex, Track R 책임 역할은 Aegis로 조건부 지정한다. 기존 Codex/Claude 경로 외 신규 API·설치·계약은 승인하지 않는다. 역할·모델·세션·실행권한은 다른 개념이다.

정확한 JD, 역할별 보고선, 제척, 공통 전략 계약은 `coordination/kidults/registry/roles-and-responsibilities.json`을 기준으로 한다. 같은 공급자와 역할명 분리는 독립성 증명이 아니다. 실제 별도 권한·세션·증거 출처를 확인한다. Deputy는 새 승인 관문이 아니며 자동 후계자도 아니다. Track R은 KPMO에 종속되지 않지만 무제한 전면 차단권을 갖지 않는다.

전략 계획은 최소 충분한 범위로 작성하며 가장 위험한 가정을 먼저 검증한다. 코드·PR·CI·병합·문서 로딩은 실제 종결을 대신하지 않는다. 속도는 재작업 감소로, 품질은 실제 회귀·복구·종단 간 증거로 측정한다.

Track C의 과거 수락·완료 이력은 삭제하지 않는다. 사람/AI·역할 등록은 현재 재수락 대기, Track의 기존 ACTIVE는 구현 자산 상태이며 현재 역할 dispatch의 허가가 아니다. 실제 전달·거부 증거 없는 교체를 금지한다.

기계 검증은 문서/역할/전략 계약 결속과 정합성을 검사한다. 외부 에이전트 launcher 강제 적용이나 실제 직무 수락은 이 PR만으로 입증하지 않는다. 미확인 역할은 dispatch_enabled=false를 유지한다. 92점 목표·필수 결격조건과 모든 Owner 유보 권한은 유지한다.
