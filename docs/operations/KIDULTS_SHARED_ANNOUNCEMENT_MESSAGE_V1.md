# KIDULTS Shared Operating Announcement — Distribution Message

## Korean

안녕하세요.

오늘부터 **Kidults 120 Score**, **Rankability Gate**, **Portal V502 & Data Connection**은 각각의 독립 채팅 프로젝트가 아니라, 하나의 **KIDULTS Integrated Intelligence Program** 안에서 운영됩니다.

세 Workstream의 역할은 다음과 같습니다.

- **Track A — Kidults 120 Score:** Right Data를 탐색하고, 품질·속도·스케일을 검증하며, 버전이 고정된 Snapshot Candidate를 발행합니다.
- **Track B — Rankability Gate:** 동일 Snapshot ID를 독립적으로 검증하고, `blocked / conditional / publishable` Gate와 정량적 Exit Criteria를 발행합니다.
- **Track C — Portal V502:** 승인된 Published Snapshot과 Production-ready Editorial Asset만 소비해 포털에 표현합니다. Portal은 Ranking이나 Readiness를 계산하지 않습니다.

공식 공유 기준은 GitHub의 `coordination/kidults/`와 Issues **#234–#238**입니다. 개별 ChatGPT 대화는 Working Room이며, 대화 안의 선언만으로는 공식 원칙이나 완료 상태가 되지 않습니다.

모든 Workstream은 하나의 `snapshot_id`, 같은 Methodology Version, 같은 Registry, 같은 Production Gate를 사용합니다.

```text
120 Snapshot Candidate
→ Independent Rankability Assessment
→ Integration Gate
→ Portal V502 Release
→ Program Owner Production Approval
```

운영 원칙:

1. 8개 Core Vertical은 안정적인 Coverage 구조입니다.
2. Featured Set, Hero, Representative Object, Signal과 Research는 데이터에 따라 바뀝니다.
3. 현재 측정치는 현재 조건에서의 관측 가능성과 준비도이며, 절대적·영구적 우위를 의미하지 않습니다.
4. Missing Data는 Missing으로 남으며, 0으로 변환하지 않습니다.
5. Provider는 측정된 Gap을 보완하는 파트너이며, **Proof before Procurement** 원칙을 따릅니다.
6. Generate, Validate, Approve, Publish 책임은 분리합니다.
7. 모든 Production Release는 Rollback Target을 가져야 합니다.
8. Master Book, Baseline Book, Architecture Book은 승인된 운영 결과와 동기화합니다.

각 Track은 자신의 Bootstrap 문서를 읽고 GitHub의 공식 Issue에서 역할 수락과 현재 상태를 보고해 주세요.

## English

Effective immediately, **Kidults 120 Score**, **Rankability Gate**, and **Portal V502 & Data Connection** operate as three independent workstreams inside one **KIDULTS Integrated Intelligence Program**.

- **Track A** produces versioned intelligence snapshot candidates.
- **Track B** independently validates the exact snapshot ID and issues the Rankability Gate.
- **Track C** renders only approved published snapshots and Production-ready editorial assets.

The canonical shared record is GitHub `coordination/kidults/` and Issues **#234–#238**. Chat sessions are working rooms and are not official by themselves.

All tracks use one snapshot ID, one methodology version, shared registries and one Production promotion process.

**One Program. One Language. One Standard. One Source of Truth.**
