# 1. Purpose

Trust Controller는 TAZ의 중앙 오케스트레이터이다.

Trust Controller는 Trust 상태만 관리한다.

다음 기능은 수행하지 않는다.

- Repository Write
- Bootstrap 구현
- Receipt 생성
- Provider 호출
- Runtime 실행
- Business Logic

---

# 2. Responsibilities

Trust Controller는 다음 기능만 수행한다.

1. Session 생성
2. Session 종료
3. Trust State 관리
4. Receipt 검증 요청
5. Dispatch 승인
6. Logging

# 5. Public Interface

```typescript
export interface TrustController {

createSession(
request: SessionRequest
): SessionResponse

verifyReceipt(
request: ReceiptRequest
): ReceiptResult

authorizeDispatch(
request: DispatchRequest
): DispatchDecision

request: CloseSessionRequest
): void

}
```
