# 1. Purpose

TAZ(Trust Architecture Zero)는 Intelligence Holdings Platform의 공통 Trust Layer이다.

본 문서는 구현 문서가 아니라 Architecture Constitution이다.

모든 구현은 본 문서를 기준으로 수행한다.

# 4. Core Principles

Rule-001

Shared Core는 최소화한다.

Rule-002

Business Logic은 Shared Core에 포함하지 않는다.

Rule-003

Provider Logic은 Adapter에서만 처리한다.

Rule-004

모든 Vertical은 동일한 Contract를 사용한다.

Rule-005

Receipt는 변경하지 않는다.

Rule-006

Provenance는 변경하지 않는다.

Rule-007

Evidence Ledger는 변경하지 않는다.

Rule-008

Trusted Merge는 변경하지 않는다.
