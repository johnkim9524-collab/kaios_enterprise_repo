# KIDULTS Portal Visual Baseline v1.0 — LOCKED

Status: LOCKED
Effective: 2026-08-08

The public portal visual system is frozen at v1.0. Autonomous Intelligence work must not change the visual baseline unless a change is required for one of the following reasons:

1. functional defect;
2. accessibility defect;
3. responsive/mobile containment defect;
4. data-integrity or provenance disclosure requirement;
5. explicit visual-baseline version upgrade.

## Locked visual grammar

- Editorial shell: warm cream / deep forest / muted gold.
- Hero: single KPI intelligence instrument; not a categorical donut.
- Categorical radial charts: Mint `#83CFBA`, Teal `#5AA3A5`, Petrol Blue `#6298B8`, Aqua Blue `#86B9D5`, Dusty Sage `#A7BEB4`.
- State/progress charts: Muted Forest `#285F53`.
- Correlation/intensity: Dusty Sage to Deep Teal sequential scale.
- Directional movement: Muted Forest for positive, restrained red for negative.
- Hero ring: same intelligence color family, single-instrument treatment.
- Typography, section hierarchy, governed-system surfaces, company band and navigation are frozen.

## Change-control rule

Backend, collector, evidence, methodology, ranking, index, publishing and API changes must remain presentation-compatible with this baseline. A visual change requires a new baseline version and explicit approval.
