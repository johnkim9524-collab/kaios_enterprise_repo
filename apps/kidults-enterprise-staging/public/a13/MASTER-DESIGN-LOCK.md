# A13 Final Master Design Lock

Status: FROZEN TARGET
Effective date: 2026-08-11
Canonical authority: `docs/design/KIDULTS_FINAL_MASTER_DESIGN.md`

## Rule

The A13 public implementation must converge to the Final Master. Existing differences are implementation debt and must not be treated as alternative design choices.

## Non-negotiable visual targets

- Header brand is uppercase tracked `K I D U L T S` in a restrained sans serif.
- Footer uses the same signature at a substantially smaller scale.
- Hero contains one large `Mobility Sculpture 01` visual only; no right-side object rail.
- Hero statement remains `Objects worth / knowing before / everyone else.`
- Palette is warm ivory + Primary Ink + Forest Intelligence + restrained neutrals.
- `COVERAGE — 500+ Tracked Entities` is the approved coverage wording in the master reference.
- Institutional Intelligence Layer remains `SIGNAL → VERIFY → ANALYZE → BENCHMARK → PUBLISH`.
- Kidult 100 uses the approved five rights-safe preview forms: Mobility, Time, Footwear, Character, Design.
- Character remains generic/non-branded, with small nose and natural arms/hands.
- Canon Strength uses Building / Emerging / Established / Canonical.
- Public footer remains lightweight ivory; no heavy forest footer.

## Data rule

Connected values must be provenance-backed. Null or unverified evidence must render as unavailable/pending, never as zero.

## Responsive rule

Desktop, tablet and mobile are adaptations of the same Final Master. No separate mobile-only visual concept is permitted.

## Change control

Any intentional deviation from the Final Master requires an explicit owner decision and a corresponding update to the canonical design documents before implementation.
