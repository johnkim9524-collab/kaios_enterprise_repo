# A13-B14 Integrated Intelligence Activation

## Objective
Complete the shortest credible path from the approved staging intelligence product to an operational multi-source intelligence system.

## Integrated Workstreams
1. Live source onboarding
   - transaction or sold-price evidence
   - listing or supply evidence
   - cultural demand or news evidence
2. Multi-source aggregation
   - normalization
   - source reconciliation
   - partial-failure tolerance
   - freshness and provenance propagation
3. Kidult 100 scoring
   - versioned weights
   - evidence minimums
   - confidence penalties
   - anomaly controls
   - reproducible output
4. Monthly Intelligence automation
   - snapshot
   - executive summary
   - category leaders
   - risk watch
   - archive registration
5. Operational certification
   - source health
   - end-to-end tests
   - mobile gates at 320px, 360px, 390px and 430px
   - production readiness report

## Delivery Model
- one integration branch
- one pull request
- sequential internal checkpoints rather than separate PRs
- existing `/a13-b10/` staging route retained
- existing one HTML, one physical CSS and one interaction JavaScript architecture retained
- JSON contracts and deterministic scripts may be added

## Safety
- Production remains untouched.
- No source may be promoted without explicit rights, provenance and freshness metadata.
- Illustrative fallback remains available until at least two independent live source families pass certification.
- Production promotion remains blocked unless all release gates pass.

## Completion Gates
- at least three registered source roles
- at least two independently healthy source families
- deterministic Kidult 100 scoring output
- automated monthly report and archive output
- total-failure fallback verified
- end-to-end and mobile regression gates pass
- production readiness status is explicit and machine-readable
